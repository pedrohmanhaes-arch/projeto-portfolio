💻 Projeto Portfólio

Este projeto consiste no desenvolvimento de um site de portfólio pessoal, criado durante meus estudos de HTML5 e CSS3 por meio do curso do Curso em Vídeo.

O objetivo foi colocar em prática os conhecimentos adquiridos ao longo das aulas, explorando a estruturação de páginas web, estilização de elementos e organização de conteúdo.

📌 Sobre o projeto

O portfólio apresenta minha trajetória profissional, formação acadêmica, habilidades e alguns projetos desenvolvidos durante minha jornada de aprendizado em tecnologia.

Atualmente, sou psicólogo clínico e social e estou construindo uma nova trajetória profissional na área de tecnologia, direcionando meus estudos para o desenvolvimento Full Stack.

🛠️ Tecnologias utilizadas

HTML5: estruturação e organização do conteúdo da página.

CSS3: estilização, layout e personalização visual dos elementos.

📚 O que foi praticado

Durante o desenvolvimento deste projeto, foram trabalhados conceitos como:

Estrutura semântica do HTML5.

Estilização com CSS3.

Organização de seções e elementos.

Inserção e apresentação de imagens.

Criação de layouts para páginas web.

Construção de uma página de portfólio pessoal.

📂 Conteúdo do portfólio

O site está organizado nas seguintes seções:

Apresentação: breve descrição pessoal e trajetória profissional.

Skills: apresentação das habilidades em tecnologia.

Formação: histórico acadêmico.

Projetos: exposição de projetos desenvolvidos durante os estudos.

🚀 Publicação
